## 简讯

- 智谱发布最新的旗舰模型：[GLM-5](https://z.ai/blog/glm-5)。
- MiniMax 发布了旗下最新模型：[MiniMax-M2.5](https://www.minimax.io/news/minimax-m25)， SWE-bench 分数高达 80.2 。
- 自 OpenAI 与 Cerebras 合作以来，模型响应速度都快了很多，现在又联合推出了转为高速推理设计的 [GPT-5.3-Codex-Spark](https://openai.com/index/introducing-gpt-5-3-codex-spark/)，响应速度可高达 1k tokens/s 。
- Cloudflare 推出了 [Markdown for Agents](https://blog.cloudflare.com/markdown-for-agents) 功能，旨在通过将 HTML 内容自动转换为 markdown，以更高效的方式为 AI 提供结构化数据。
- Ladybird 浏览器项目也[开始 Rust 化](https://ladybird.org/posts/adopting-rust/)了。
- OpenAI 宣布在 Responses API 上[支持 WebSockets](https://developers.openai.com/api/docs/guides/websocket-mode)，对于需要调用大量工具和长时间运行的 Agent 来说有很大的优化帮助。
- Google DeepMind 发布了 [Nano Banana 2](https://blog.google/innovation-and-ai/technology/ai/nano-banana-2/)（即 Gemini 3.1 Flash Image）。
- Node.js 也要[按年号发 LTS 了](https://nodejs-org-git-fork-ulisesgascon-release-announcement-openjs.vercel.app/en/blog/announcements/evolving-the-nodejs-release-schedule)。
- 开源项目 tldraw [将项目的测试相关代码闭源](https://github.com/tldraw/tldraw/issues/8082)。（考虑到现在很容易用 AI 根据测试用例来复刻一个工具/产品
- [ggml.ai 加入了 HuggingFace](https://github.com/ggml-org/llama.cpp/discussions/19759) （挺合理的
