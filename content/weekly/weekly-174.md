## 有趣

- [openresponses](https://github.com/openresponses/openresponses)
  
    现在各个 AI 工具兼容的 Chat Completion API 是 OpenAI 一个周末赶工出来的产物，有很多局限性，整体实际还是围绕着回合制的对话来设计的。后面有 Assistants API，体验不太好，然后又推出了 [Responses API](https://developers.openai.com/blog/responses-api/) ，设计改成以 Agent Loop 为核心。现在 OpenAI 基于 Responses API 整了个 Open Responses ，默认兼容多个厂商的调用，旨在成为下一代 LLM API 的调用规范。
