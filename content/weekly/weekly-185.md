## 简讯

- Kimi 开源了最新模型 [Kimi K2.6](https://www.kimi.com/blog/kimi-k2-6)，主打 coding、长周期执行和 agent swarm 能力，并已开放给 Kimi.com、Kimi App、API 和 Kimi Code 使用。
- Apple 宣布一项[重大高层交接](https://www.apple.com/newsroom/2026/04/tim-cook-to-become-apple-executive-chairman-john-ternus-to-become-apple-ceo/)：Tim Cook 将在 2026 年 9 月 1 日转任执行董事长，John Ternus 将接任 Apple CEO。
- SpaceX 在 X 上宣布，[SpaceXAI 和 Cursor 将深入合作](https://x.com/SpaceX/status/2046713419978453374)，目标是做出面向 coding 和知识工作最强的 AI。而且 Cursor 今年晚些可以选择被 SpaceX 以 60 billion 美元收购；如果不收购，则 SpaceX 需要为合作支付 10 billion 美元。
- Anthropic 短暂[修改了 Claude 的定价页面](https://simonwillison.net/2026/Apr/22/claude-code-confusion/)，把 Claude Code 从 $20/月的 Pro 订阅移到 $100/月和 $200/月的 Max 订阅，引发大量争议后又迅速撤回。官方随后称这是面向约 2% 新订阅用户的小范围测试。
- GitHub 对 [GitHub Copilot 个人版](https://github.blog/news-insights/company-news/changes-to-github-copilot-individual-plans/)动手了：不仅收紧了用量，还暂停了个人订阅的新注册，并把 Claude Opus 4.7 只放进更贵的 Pro+ 套餐里。
- Qwen 发布了 [Qwen3.6-27B](https://qwen.ai/blog?id=qwen3.6-27b)，主打 27B dense 规模却给出接近旗舰级的 coding 表现，在 benchmark 上超过了上一代更大的 Qwen3.5-397B-A17B。
- OpenAI 发布了最新的图像模型：[gpt-image-2](https://openai.com/zh-Hans-CN/index/introducing-chatgpt-images-2-0/) ，CJK 文字渲染能力大大提升。
