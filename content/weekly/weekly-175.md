## 工具

- [agent-browser](https://github.com/vercel-labs/agent-browser)
  
    Vercel 发布的一个基于 Playwright 的浏览器自动化 CLI 工具，可以使用它的 Skill 替代 Playwright MCP。
    
- [skills.sh](https://skills.sh/)
  
    也是 Vercel 发布的一个 Skills 集合网站。
    
- [json-render](https://github.com/vercel-labs/json-render)
  
    也是 Vercel 发布的一个库，可以让用户通过 AI 生成定制好的 UI 组件。
    
- [agentation](https://github.com/benjitaylor/agentation)
  
    一个给 Agent 做视觉标注的工具，方便跟 AI 指哪打哪。
    
- [ChartGPU](https://github.com/ChartGPU/ChartGPU)
  
    通过 WebGPU 来调用 GPU 绘制图表的库。
    
- [Pencil.dev](https://www.pencil.dev/)
  
    一个可以让 AI Agent 驱动的无限设计画布。
    
- [clawdbot](https://github.com/clawdbot/clawdbot)
  
    一个支持私有部署的个人 AI Agent 方案，支持非常多的应用集成。
